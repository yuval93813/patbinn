# Python dependencies for PatBiNN.

#     pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu124
#
# The ART Illumina read simulator is likewise installed by patbinn.def via
# conda (bioconda::art) and is not a pip package.

# against; upper bounds guard against the next major release.
